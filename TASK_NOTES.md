# Task 3 notes

The supplied task screenshots require a Python salary analysis, a manually created dataset,
salary statistics, and a README. They list Jupyter Notebook, but the requested working method
for this submission is terminal-only. Therefore the core analysis is provided as `salary_analysis.py`
and the browser dashboard is served by `app.py` using only Python's standard library.

The project does not depend on Jupyter, pandas, Flask, Node.js, npm, or other external packages.
